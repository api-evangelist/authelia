### Authentication

> Authentication

- [Authentication](https://www.authelia.com/overview/authentication/introduction/): An overview of a authentication.
- [First Factor](https://www.authelia.com/overview/authentication/first-factor/): Authelia utilizes the standard username and password combination for first factor authentication.
- [One Time Password](https://www.authelia.com/overview/authentication/one-time-password/): Authelia utilizes Time-based One-Time Passwords as one of it's second factor authentication methods.
- [Security Key and Passkeys](https://www.authelia.com/overview/authentication/security-key/): Authelia utilizes WebAuthn Credentials as one of it's second factor authentication methods and a passwordless login method via Passkeys.
- [Duo / Mobile Push](https://www.authelia.com/overview/authentication/push-notification/): Authelia utilizes Duo Push Notifications as one of it's second factor authentication methods.
- [Password Policy](https://www.authelia.com/overview/authentication/password-policy/): Authelia implements a password policy feature.

### Authorization

> Authorization Overview

- [Access Control](https://www.authelia.com/overview/authorization/access-control/): Access Control is the main authorization system in Authelia.
- [Regulation](https://www.authelia.com/overview/authorization/regulation/): Regulation of failed attempts is an important function of an IAM system.
- [OpenID Connect 1.0](https://www.authelia.com/overview/authorization/openid-connect-1.0/): OpenID Connect 1.0 is a authorization identity framework supported by Authelia.
- [Trusted Headers SSO](https://www.authelia.com/overview/authorization/trusted-headers/): Trusted Headers SSO is a simple header authorization framework supported by Authelia.
- [Statelessness](https://www.authelia.com/overview/authorization/statelessness/): Statelessness is the ability for a system to operate without an in-memory state. A crash could result in loss of the in-memory state causing a bad user experience.
